# Libellus performance 1.1.2

Release build. Same harness for the baseline and later runs.
`spend` reads the ledger once, under the lock. Compared with the recorded
1.0.0 baseline on this harness, a spend against 10000 stored entries moved
from median 20240 us (p95 21385) to median 14969 us (p95 15455).

The 1.1.0 note said that spend had already stopped reading the ledger twice
and had fallen to about 14065 us. That second read was still in the code, so
that spend figure is not a result to keep. This file is the remeasurement.
